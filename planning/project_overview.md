# Project Overview: L903-Manga

## Description
L903-Manga is a manga reader web application built with Next.js 15 (App Router) and MangaDex API. It focuses on clean UI, fast navigation, and responsive performance even on low-end PCs and mobile devices.

## Main Goals
- **Responsive & Low-End Friendly Reading Experience**: Fast loading times, GPU-light styling, and minimal blocking animations.
- **Clean Dark UI**: Curated dark theme (`globals.css`) with lightweight translucent surfaces and clear typography.
- **Predictable Data Fetching**: Using `TanStack React Query` for caching/server state alongside `Next.js` Server Component prefetching and API proxy caching.
- **Modular Architecture**: Organized codebase (`src/codebase/`, `src/components/`, `src/app/`) to ensure maintainability and scalability.

## Target Audience
Manga enthusiasts looking for a clean, feature-rich, and fast reading platform.
